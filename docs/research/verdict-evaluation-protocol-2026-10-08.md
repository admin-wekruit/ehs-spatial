# 判定层怎么评、怎么泛化（2026-10-08）

用户的问题：别人的系统我们很难逐个验证；我们会有很多 safety specs，相似工位里的东西又各不相同，怎么泛化？评测是不是"全部跑一次、规定好输出"？

**答案：是。固定一个基准集、固定一个输出 schema、每个版本整套跑一次、按分层记分、留出工位和留出规范来量泛化。** 别人的论文结论我们不验证，只把它们当设计选项，用消融在我们自己的基准上验证。

## 1. 固定什么

| 固定项 | 内容 |
|---|---|
| 基准集 B | (工位, 照片集, 规范包) 的三元组。规范包 = 版本化的规则集（ISO 13857 / 13855 / 13854、IEC 60204-1、OSHA 1910、客户站点规则各一包）。工位先从 090 / 030 + 合成工位起 |
| 输出 schema | 每个 (工位, 规范包) 产三个文件：`verdicts.json`（每条 = rule_id@version、subjects、status ∈ {PASS, FAIL, NEEDS_MEASUREMENT, NEEDS_INPUT, CANNOT_DETERMINE}、measured ± U、threshold、evidence refs）、`coverage.json`（哪些条款被检索 / 编译 / 跳过及原因）、`gaps.json`（unknown_inputs、对齐低置信行、词表缺口）。schema 冻结，版本号跟着改 |
| 金标 | 每个 (工位, 规则, 对象)：人工判定（五态之一）+ 现场测量值（卷尺 / 激光）+ 适用性决定；双人标注 + 仲裁，Krippendorff α ≥ 0.8；记录标注者和日期 |
| 感知缓存 | 判定层评测时冻结感知输出（场景图），这样判定层的变化不被重建噪声淹没；感知层另有自己的评测 |
| 跑法 | 每个流水线版本把 B 整套跑一次，确定性，产一张记分卡；CI 里对金标快照 diff，任何判定翻转即失败 |

## 2. 记什么分（按层、按规则类、按状态分层）

| 层 | 指标 |
|---|---|
| 规范 → 检查 | 编译率（可执行且未拒绝）、误拒率、冗余翻译不一致率（歧义代理）、每条审阅分钟数、需人工修的比例 |
| 对齐 | 条款词 → 场景类别 / 区域 / 属性的覆盖率和精确率（对工程师给的对齐表） |
| 检索 | 适用条款召回（对工程师给的每工位清单） |
| 感知 | 每对象尺寸 / 位置误差；σ 校准（真误差落在 ±2σ 内 ≈ 95 %）；类别精确率 / 召回 |
| 判定 | 5×5 状态混淆矩阵（人工 vs 机器）；FAIL 召回 ≥ 0.95、精确率 ≥ 0.80；NEEDS / CANNOT 率（报告，不惩罚，除非 > 50 %）；护带覆盖（人工说 FAIL 的里机器说 PASS 的 = 零容忍项） |
| 解释 | 审核员一分钟内追到照片 + 数字的比例；系统"缺什么"清单与工程师清单一致率 |

## 3. 泛化怎么量：留出工位、留出规范

| 划分 | 问什么 |
|---|---|
| (a) 已见工位 + 已见规范 | 开发集，看上限 |
| (b) **未见工位** + 已见规范 | 新的物体排布 / 新类别：对齐表能不能接住？coverage 掉多少？ |
| (c) 已见工位 + **未见规范包** | 新条款能不能编译、检索、对齐？编译率掉多少？ |
| (d) 未见工位 + 未见规范 | 真实部署的情形；报告退化曲线 |

分层维度：对象类别、规则类（几何 / 拓扑 / 语义）、工位原型（机器人围栏工位、光幕工位、AGV 通道、压机、输送线…）。
真实工位少 → 用参数化合成工位（Isaac Sim / NVIDIA SDG-Warehouse）填原型矩阵，真实工位做校准和分布迁移检验。
"相似工位里东西各不相同"的处理：类别 / 区域签名 + 对齐表吸收新物体；每个新工位出 coverage 报告（哪些规则能判、哪些 NEEDS_INPUT、哪些 CANNOT），泛化 = 未见原型上的 coverage × 准确率，不是单一数字。

## 4. 怎么"验证别人的结论"：消融，不是复现论文

每个从文献学来的设计选项做成开关，在 B 上开 / 关各跑一次，看 delta（GuardEn 的做法）：验证循环、同义词重落地、检索、护带、对齐表、感知规约。
delta 为正且显著才留；这就是我们验证"别人做的是否对我们有用"的方式，不需要信论文。

## 5. 规模与成本

- N 个工位 × M 条规则不必全标：按"规则类 × 工位原型"矩阵覆盖，每格 ≥ 40 个实例、≥ 10 个 FAIL；30–60 个场景覆盖 12 条规则的量级（调研 B）。
- 视频阶段：标事件不标帧；合成视频给逐帧真值；主动抽帧只标护带内 / 高不确定度片段（研究主文 F3）。
- 每次规范改版：规则包版本号 + 金标快照重跑 + diff 报告（Han et al. 的 −94 % 变更处理成本就来自这一套）。

## 6. 第一版基准（可以现在定）

- 工位：090、030 + 3 个合成原型（围栏工位、光幕工位、AGV 通道）。
- 规范包：ISO 13857 + 13855 的 20 条条款（有表格和公式的）+ 客户站点规则（待用户提供）。
- 金标：两个真实工位的现场测量已有一部分（罩壳 24.0、横杆 21.0 cm 等）；判定金标由安全工程师双标。
- 输出：上面三个 JSON + 记分卡 markdown；记分卡进 `docs/MILESTONES.md` 的里程碑表。
