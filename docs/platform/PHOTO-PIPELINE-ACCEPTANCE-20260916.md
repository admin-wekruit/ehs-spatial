# Photo-to-report correspondence: acceptance remains open

The delivery target is one owned object identity linking source-photo evidence,
CAD and browser-visible model geometry, through the same analysis path for every
new capture. Counts, downloadable Blender files and successful GPU processes are
not acceptance of shape or correspondence.

## Reusable path and measured stage executions

Capture analysis, explicit object generation and quality review use immutable
source IDs, bytes, selected observations, provider pins and configuration. CAD
validation and model quality are evaluated independently of model availability.
An owned empty capture can prepare geometry or depth validation without already
having the outputs those stages are intended to create. Preparation does not
invoke a model or write a scene.

Runtime validation retains unverified release gates. The first Map run predates
mandatory adapter-file SHA binding; its original envelope and result remain
unchanged. Subsequent geometry/depth deployments require the exact adapter-file
SHA as well as immutable model/code/image identities, and the frozen stage hash
is checked before inference. MoGe's validation includes that adapter binding.
A changed deployment cannot silently execute a differently pinned queued input.

Both product and research paths validate returned geometry/depth contents before
reporting stage success. A matching model name or pins with an empty, foreign-grid
or invalid response fails. Hash-verified returned artifacts remain available for
diagnosis, without a second paid request merely to repeat validation.

The complete Python suite after these output-contract changes passed 1,011 tests;
29 environment-dependent tests were skipped. This is code/transaction evidence,
not proof that a new uploaded workcell finishes with accepted models.

  approval. The last authenticated check returned 403. Its required pose,
  mesh-only and multi-view quality validation has not run successfully.
- Missing geometry and actual silhouette/depth failures require source-backed
  correction, followed by every applicable photo and CAD check. No threshold was
  loosened to admit the rejected candidates.

  executions do not establish this result.

  separate unfinished release gate.
