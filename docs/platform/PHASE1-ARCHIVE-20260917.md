## 保留的验收缺口

1. **完整新输入闭环。** 发现→分割→关联→生成→质量核验→CAD→真实报告尚无通过的全新照片端到端发布验收；必须逐项确认现场实体与关键部件，不能只核对记录总数。
2. **物理身份与几何质量。** 历史关联中的竞争候选、缺观察及跨视角深度不一致仍各自需要证据；整理版覆盖不撤销尚未确认的形状、位置与质量状态。030 后续修复版本保留 81 条业务记录、82 条观察、2 个生成模型，未完成整体建模；其来源修复验收不代表模型完成。
3. **测量有效性。** 原生单位不自动是米；地面方向误差、尺度及留出照片/现场参考尚未完成独立验证。折弯检测仍只寻找一处主要折弯，可能漏掉窄小、多折或圆弧连接；局部面检测存在采样和跨架构拟合差异。当前示例版本尚未重新运行安全评估，历史 EHS 结果不得当作当前结论。
4. **生产入口与 provider 验收。** 冻结报告服务、实际观测上传服务和完整 platform provider/worker 配置是不同交付项，完整链路仍需实际入口验证。照片验收文档的 2026-09-16 认证记录曾返回 SAM3D `403 GatedRepo / account_access_not_approved`；后续粗模型交付已复用成功的 hosted SAM3D 输出。两者是不同时间/路径的证据，**本归档未重测当前 gated 权重权限，也不将旧 403 当作所有生成路径当前不可用的结论**。
5. **全场景交互验收。** 已有整理版局部操作通过记录；历史大场景冷加载、逐实体/部件双向选择与连续自由旋转仍须在将要交付的同一 revision 实测，不能由源码、导出文件或后台成功记录替代。
