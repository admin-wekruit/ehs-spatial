## Hazard（ISO 12100:2010 危险识别，不是完整风险评估）

- 任务 = 正常运行中的人工上下料：人在开口处放料，机器人或输送机取走。危险区 = 开口内及周围人可能暴露于危险的空间。（ISO 12100:2010, 5.4, 5.5.3.2, 3.10, 3.11; Table B.3）
- 机械危险：运动部件 —— 挤压、剪切、切割 / 切断、卷入 / 困住、缠绕、撞击；清理故障时仍可能被困在搬运装置与机器 / 工件之间。不给严重度和概率。（ISO 12100:2010, 3.6, Table B.1, 6.2.14）

## Protective purpose（风险降低第 2 步）

- 三步法：步骤 1 本质安全设计（含自动化上下料减少暴露）；本工位人仍在开口放料，危险未消除；步骤 2 防护和补充保护措施；步骤 3 使用信息。（ISO 12100:2010, 6.1, 3.19–3.22）
- 开口处用敏感保护设备（AOPD）而不是可能被拆掉的固定防护；急停是补充保护措施；信号塔是使用信息里的信号，不是防护。（ISO 12100:2010, 6.3.1, 6.3.2.1, 3.26, 3.27, 3.28.5, 3.28.6）

## Configuration requirements（"Advisory interpretation, not a compliance sign-off. Dimensions on the canvas are unscaled concept millimetres"）

1. **有操作交互的固定屏障最低 1000 mm**：人上下料处的最低高度；不是越过控制，也不是防攀爬。无操作交互的屏障至少 1400 mm。固定屏障下开口最多 180 mm。（TS-0011963 Rev 10, 8.1.4–8.1.6）
2. **攀爬由防护结构控制**：尽可能抑制攀爬，如不设外侧水平构件、网孔无水平分量；安全距离的假设不含攀爬和跳跃。（ISO 14120:2015, 5.18; ISO 13857:2019, 4.1.1）
3. **上料区：水平 AOPD 或区域扫描仪**：垂直光幕与危险之间的空间由水平光幕或区域扫描仪保护；任一被遮断即视为有人。垂直感应面与水平面前缘的间隙最多 70 mm。人不能站在水平光幕上或挂在周界物体上而不被检测。（TS-0011963 Rev 10, 9.1.5, 9.1.6, 9.1.8）
4. **水平光幕不高于 300 mm**：术语 = 平行于参考面的检测区；ISO 13855:2024 允许到 1000 mm 且 200 mm 以上要评估下方进入；本工位用更严的 Tesla 限值 300 mm。（TS-0011963 Rev 10, 9.1.7; ISO 13855:2024, 9.2）
5. **上料入口的垂直光幕**：考虑越过、穿过、下方伸入，分离距离取三者最大。上缘离地 1800 mm 或 ISO 13857 越过所需高度，取大者；下缘 300 mm，或 ISO 13857 要求更低则更低。布置还取决于分离距离和停止时间。光束间距 14 mm。停止时间不在模型里，毫米距离这里不算。脚注引 ISO 13855:2010，手上正文是 2024 版。（TS-0011963 Rev 10, 9.1.1–9.1.4, 9.1.9; ISO 13855:2024, Formula (13), 8.3, 8.4）
6. **水平长度 = 分离距离 + 检测深度**：从离危险最远的边：S = (1600 × T) + 1200 + Z。区深：有 ≥ 70 mm 深的踏脚面在其后时至少 1200 mm；有结构阻止人未被检测跨过时至少 900 mm。T 和 Z 未给，不写单一合规长度。（ISO 13855:2024, 9.3, 9.4）
7. **侧屏障用越过表，不是固定 2200 规则**：用 ISO 13857:2019 表 2（高风险；机器人单元周界也要求）。2200 mm 是表中一个防护高度：危险点 ≤ 1800 时水平安全距离 0；危险点 2000 / 2200 / 2400 / 2600 时 400。低于 1400 的防护结构不单独使用。表值不插值。机器人单元周界在越过距离之外再加负载停止距离：< 150 kg 加 150 mm；150 ≤ 负载 < 300 kg 加 500 mm；≥ 300 kg 加 700 mm 或制造商最坏情况。本工位负载未知。（ISO 13857:2019, 4.2.2, Table 2 note c; TS-0011963 Rev 10, 10.6.3, 10.6.4, Table 10-3）
8. **急停和独立复位**：急停在操作者正常工作位置可及范围内。人工工位只有控制装置本质安全且风险评估支持时才可省略；本工位含机器人单元，不假设豁免。每个供整身进入的安全门都有急停。按钮为黄底红蘑菇头、旋转释放、离地 0.6–1.7 m。急停不替代光幕、门开关或上锁挂牌。仅复位急停不恢复危险动力；独立的物理安全复位按钮才恢复。复位与启动分开、不启动危险、位于危险区外且能看见区内。（TS-0011963 Rev 10, 4.3.1–4.3.7; ISO 13849-1:2023, 5.2.2.3）
9. **信号塔是状态信号不是防护**：250–400 mm/s 有人值守的输送要求设备状态信号塔和启动报警；没有条款要求每个人工上料工位都有信号塔。视觉 / 听觉信号在危险事件前给出且无歧义。灯色顺序不是要求。（TS-0011963 Rev 10, 11.1.2; ISO 12100:2010, 6.4.3）

## 装置说明与量测读数（页面"Measure"）

- Stack light（ISO 12100:2010, 6.4.3）：信号塔；最低离地 2180 mm，最高 2682 mm，竖向高度 502 mm。
- Solid fence（ISO 12100:2010, 3.27 and 6.3.2.2 a); ISO 14120:2015）：灰色实心板固定围栏；最低 0 mm，最高 2200 mm，竖向高度 2200 mm。
- 画面：机器人在中央台座上，四周网状 / 实心围栏，前方上料开口有垂直光幕（黄色立柱）+ 水平光幕，一侧有实心门板，信号塔在机器人旁。

## 对我们的意义

- 这是"已批准工位"的概念：按批准，适用规则应全部 PASS —— 可作金标来源（见回答）。
- 新出现的要求类型：按**操作交互**分的屏障高度（1000 / 1400）、水平光幕高度 ≤ 300、垂直光幕上缘 ≥ 1800 / 下缘 ≤ 300 / 光束间距 14、垂直面与水平面前缘间隙 ≤ 70、负载停止距离附加（按 payload 分档）、急停高度带 0.6–1.7 m、安全门必有急停、复位在区外。词表要加：类别 `stack_light`、`area_scanner`、`safety_door`；属性 `orientation`（光幕竖 / 横）、`operator_interaction`；声明输入 `payload_kg`、`zone_depth_mm`。
